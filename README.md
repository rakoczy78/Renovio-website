# RAKO Bau & Sanierung — wersja strony

Gotowa statyczna strona DE/PL/EN. Wgraj pliki `index.html` i `wrangler.jsonc` do głównego katalogu repozytorium GitHub.

**Przed uruchomieniem produkcyjnym:**
- Uzupełnij rzeczywiste dane firmy i kontakt (brak danych w kodzie jest celowy).
- Podłącz bezpieczny backend formularza i potwierdzenia e-mail; formularz celowo nie wysyła danych.
- Przygotuj austriackie Impressum i Datenschutzerklärung; obecne teksty są tylko ostrzeżeniem.
- Zastąp zdjęcia inspiracyjne własnymi realizacjami (z prawami do publikacji).
- Sprawdź licencje i dostępność obrazów z Unsplash.
- Sprawdź stronę na telefonie i desktopie po wdrożeniu.

Nie ma jeszcze działającej rezerwacji terminów ani wysyłki wiadomości.
